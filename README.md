# EDA#

Un ancien projet créé pour un tournoi de programmation (Trophées NSI).

Le but était de créé une plateforme avec un jeu sur une carte 2d avec de simple instruction, qui permettait d'initier à la logique de programmation.
Le projet dans l'état où on l'a laissé à l'époque ne marche pas parfaitement à cause de deux choses:
- Flask est un package assez limité qui n'est pas fait pour ce genre d'application
- Le langage avait été créé sans utilisation de la théorie des langages (automates ou grammaire non contextuelle), même si l'idée de traduire un programme en lexème était là, le code derrière pourrait être beaucoup plus simple et fiable.
